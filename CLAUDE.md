# CLAUDE.md — snackbyte-site

## Client sections

`src/web/public/work/<slug>/` holds self-contained client sections, published from
other repos — sometimes by agents that never open this one. Before touching
anything under `work/`, read `docs/SECTIONS.md`; it is the contract, and it binds
contributors from outside this directory as much as work done inside it.

The short version: a contributor writes only inside its own section folder, pages
are standalone HTML, `section.json` is the manifest, and the section's root
`index.html` is generated by `scripts/build-sections.mjs` on every build.

Sections are never linked from the homepage.

## Brand

The brand lives outside this repository. The guide — values, rules, voice — is
[`snackbyte-brand`](https://github.com/jeff-fichtner/snackbyte-brand) and is the
authority; [`snackbyte-brand-render`](https://github.com/jeff-fichtner/snackbyte-brand-render)
compresses it into `@snackbyte/brand`, which this site consumes: `tokens.css` and
`base.css` in `main.tsx`, the mark's path data in `Logo.tsx`, favicons and the
link-preview card copied into `public/` at build.

**Never write a brand value here** — no hex, no scale step, no mark geometry. Change
it in the guide, bump the tag, rebuild. Page styling belongs in `src/web/app.css`;
`docs/BRAND.md` is a pointer, and <https://snackbyte.io/style/> is the readable
version, served from this repo.
